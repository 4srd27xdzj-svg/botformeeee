# TikTok Downloader Bot for Telegram

Бот получает ссылку на публичное видео TikTok, скачивает его и присылает документом в Telegram.

Используйте только для роликов, на скачивание и распространение которых у вас есть права; приватные и удалённые видео бот не обрабатывает.

## Что нужно от вас

1. Создайте бота через [@BotFather](https://t.me/BotFather): команда `/newbot`.
2. Скопируйте выданный `BOT_TOKEN`.
3. Установите Python 3.9+ и `ffmpeg` (на macOS: `brew install ffmpeg`).

## Быстрый запуск

```bash
cd /Users/artemii/Documents/Codex/2026-10-08/new-chat
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Откройте .env и вставьте настоящий BOT_TOKEN
python bot.py
```

Откройте диалог с вашим ботом, отправьте `/start`, затем ссылку на TikTok.

## Если TikTok не отвечает

TikTok иногда ограничивает обращения с серверов. Укажите в `.env` строку `PROXY_URL=http://...` с вашим прокси и перезапустите бота. Также полезно обновить загрузчик:

```bash
pip install -U yt-dlp
```

## Ограничения

- Только публичные TikTok-ссылки.
- Размер отправляемого файла ограничен 49 МБ — лимитом обычного Telegram Bot API.
- Бот работает, пока запущена команда `python bot.py`. Для постоянной работы его нужно разместить на сервере или VPS.

## Деплой на Bothost

1. Создайте **приватный** репозиторий GitHub и загрузите в него эти файлы. Не добавляйте `.env` — он уже указан в `.gitignore`.
2. В Bothost создайте Telegram-бота, выберите стек **Dockerfile** (или включите FFmpeg в настройках) и укажите Git-репозиторий.
3. В переменных окружения Bothost добавьте `BOT_TOKEN` со значением токена от @BotFather.
4. Укажите точку запуска `bot.py` и нажмите Deploy.

После успешной сборки бот работает круглосуточно. Видео скачиваются во временную папку контейнера и удаляются сразу после отправки.
